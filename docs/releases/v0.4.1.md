## Port Store 0.4.1

- **Updates of Port Store itself are offered again** when it was installed by unzipping a
  release: Port Store now goes by its own version, not by an install record that an unzipped
  release does not have. (0.3.0 and 0.4.0 put on the card that way never saw an update.)
- A new release reaches the catalog within minutes of being published, not at the next daily
  build.

From 0.4.0 installed by Port Store: Updates → Port Store. From an unzipped 0.3.0 or 0.4.0:
unzip **PortStore-0.4.1.zip** to the root of the SD card once more.
