## Port Store 1.3.1

Dependencies get a tab of their own; love-mini and its games are together in a **LÖVE**
folder of MiyooPorts; and OnionOS's own Ports can go, its ports then showing in MiyooPorts too.

### Install

1. Download **PortStore-1.3.1.zip** below.
2. Unzip it to the **root of the SD card** (it contains `App/PortStore`; merge with the
   existing `App` folder).
3. On the Mini: **Apps → Port Store**.

Coming from 0.4.1 or later: Port Store offers this update by itself.

### New

- **Dependencies tab.** What ports run on — love-mini for its games — has a tab of its own,
  next to Homebrew: install it or update it there, and see how many games need it. It is no
  longer among Apps. A game's page says what it runs on, and whether that is on the card.

- **Folders in MiyooPorts.** A port can name a folder of MiyooPorts for its launchers
  (`folder` in its recipe, or in a porter's catalog). love-mini's games and love-mini's own
  *check* and *diagnose* entries go into **LÖVE**. Ports already installed move there when
  Port Store next starts; the folder goes when its last game is removed. Pictures stay where
  MainUI looks for them.

- **OnionOS's Ports, hidden if you like** (L2 → **ONIONOS PORTS**). The ports you put on the
  card yourself, or from Package Manager, move into MiyooPorts' **Ports** folder, and Games →
  Ports goes away: one place for every port. Switched back, everything returns to Ports as it
  was. Ports that come into Ports later (~Import ports, Package Manager) are taken in on Port
  Store's next start. Ports Collection stays installed: games start through it.
