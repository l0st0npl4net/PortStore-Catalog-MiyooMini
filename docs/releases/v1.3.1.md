## Port Store 1.3.1

LÖVE games together: in MiyooPorts, love-mini and the games that run on it are in a folder
of their own, **LÖVE**, not among the other ports.

### Install

1. Download **PortStore-1.3.1.zip** below.
2. Unzip it to the **root of the SD card** (it contains `App/PortStore`; merge with the
   existing `App` folder).
3. On the Mini: **Apps → Port Store**.

Coming from 0.4.1 or later: Port Store offers this update by itself.

### New

- **Folders in MiyooPorts.** A port can name a folder of MiyooPorts for its launchers
  (`folder` in its recipe, or in a porter's catalog). love-mini's games and love-mini's own
  *check* and *diagnose* entries go into **LÖVE**. Ports already installed move there when
  Port Store next starts; the folder goes when its last game is removed. Pictures stay where
  MainUI looks for them.

### Known limits

- Everything else as in 1.3.0.
