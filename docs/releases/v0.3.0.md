## Port Store 0.3.0

### New

- **Updates itself.** The catalog is downloaded each time Port Store starts; when a new Port
  Store is out it offers to update at once and starts again by itself. (From 0.2.0, update
  once more under Updates: from then on it is automatic.)
- **Several ports at once.** X marks ports in the list, Start installs the marked ones one
  after another. On the Updates tab, Select updates them all.
- **Newest first.** R2 sorts the list by release date (again: A to Z).
- **Without Wi-Fi.** When there is no connection, Port Store lists what it needs in
  `App/PortStore/downloads/to-download.txt`: the newest catalog and each file, with its
  address. Bring them on a computer into that folder: a catalog there (`index.json`) is used
  when it is newer, files are installed from there. Step by step in the
  [README](https://github.com/l0st0npl4net/PortStore-Catalog-MiyooMini#without-wi-fi).
- **7z releases**, unpacked with Onion's 7-Zip: **OpenRCT2** joins the catalog. Its own
  shortcut never showed in Onion; Port Store makes one that does, once your RCT2 files are in
  `Roms/PORTS/Games/OpenRCT2mini/rct2`.
- A line marks the end of a group (Miyoo64, joyrider3774 games) in the list.

### Install / update

From 0.2.0: Port Store → Updates → Port Store. New install: unzip **PortStore-0.3.0.zip** to
the root of the SD card, then Apps → Port Store.
