## Port Store 1.2.0

Over 1,600 homebrew games, demos and tools for Game Boy, Game Boy Color, Game Boy Advance and
NES, from [Homebrew Hub](https://hh.gbdev.io). Seven more ports, added without recipes. A window
for what is new in the catalog. Port Store can also have its own entry in Games, for
Favorites.

![Homebrew](https://raw.githubusercontent.com/l0st0npl4net/PortStore-Catalog-MiyooMini/main/docs/screenshots/homebrew.png)
![A homebrew page](https://raw.githubusercontent.com/l0st0npl4net/PortStore-Catalog-MiyooMini/main/docs/screenshots/homebrew-page.png)

### Install

1. Download **PortStore-1.2.0.zip** below.
2. Unzip it to the **root of the SD card** (it contains `App/PortStore`; merge with the
   existing `App` folder).
3. On the Mini: **Apps → Port Store**.

Coming from 0.4.1 or later: Port Store offers this update by itself.

### New

- **Homebrew tab.** Homebrew Hub's archive (the collection behind gbdev.io, gbadev.org and
  nesdev.org) has about 1,600 games, demos, tools and music for GB, GBC, GBA and NES. Each
  entry shows its screenshot, developer, dates, licence and description.
  - Select filters by system or kind; R2 shows the newest additions first.
  - A goes straight into OnionOS's own folder for the system (`Roms/GBA`, `Roms/GBC`,
    `Roms/GB`, `Roms/FC`) with box art, so it is in Games next to your other games.
  - X removes the ROM and its art; saves stay.
  - Every ROM is checked against the list before it touches the card. The list is rebuilt
    every day and downloaded when you open the tab.
- **Ports without recipes.** A port in MiyooMini-Ports whose release is already laid out for
  the card is now taken by itself, checked by the catalog build like any other, and marked
  `AUTO`. Among the first: Hexen II, Zuma Deluxe, SkiFree, PocketFlex and guide-watch.
- **New arrivals.** When the catalog has ports it did not have at your last look, a window
  lists them as Port Store starts (A opens one). New ports are marked `NEW` for two weeks.
- **Port Store in Games.** Turn it on in the system window (L2) to give Port Store an entry
  in Games → MiyooPorts, so you can add it to Favorites.
- **Cleanup scripts.** A port shipping `portstore-uninstall.sh` (or `mixtape-uninstall.sh`, the
  same script Mixtape runs) has it run before its files are removed, to undo what it changed
  elsewhere.

### Also

- Large screenshots are made small when read, and only a limited number of pictures are kept
  in memory, so browsing long lists never fills the Mini's memory.
- Installed homebrew is listed at the end of the Installed tab.

### Known limits

- **Homebrew needs Wi-Fi,** or the ROM brought into `App/PortStore/downloads` under the name
  its page gives.
- **Homebrew updates are not in Updates.** A newer ROM shows `UPDATE` in the Homebrew and
  Installed tabs, and is installed from its page.
- **Homebrew pictures load gradually,** a few seconds for a screenful the first time.
- **Ports that still need a recipe:** releases laid out otherwise, or offered in several
  files with none plainly the one, stay under More.
- **Not yet tried on the devices:** the tube's effects on a Mini, and the Mini v4 and Mini
  Flip. Reports welcome.
