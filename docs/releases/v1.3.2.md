## Port Store 1.3.2

Dependencies get a tab of their own.

### Install

1. Download **PortStore-1.3.2.zip** below.
2. Unzip it to the **root of the SD card** (it contains `App/PortStore`; merge with the
   existing `App` folder).
3. On the Mini: **Apps → Port Store**.

Coming from 0.4.1 or later: Port Store offers this update by itself. (The release named
v1.3.1a was this one under the number 1.3.1: Port Store did not offer it as an update.)

### New

- **Dependencies tab.** What ports run on — love-mini for its games — has a tab of its own,
  next to Homebrew: install it or update it there, and see how many games need it. It is no
  longer among Apps. A game's page says what it runs on, and whether that is on the card.

### Known limits

- Everything else as in 1.3.1.
