## Port Store 0.5.0

- **Your game files, the easy way.** Copy them from your computer into `App/PortStore/import`
  as they are, whole folders too ("Undertale (Windows)", "RollerCoaster Tycoon 2", Half-Life's
  folder with `valve` in it), and N64 ROMs for Miyoo64. On the port's page Port Store says what
  it found and where it goes; **Start** moves it into place.
- **Updates in Apps:** the number of updates shows under Port Store's name in Apps, so you see
  them without opening it.
- **Mini v4 and Mini Flip:** Port Store uses the whole 752×560 screen, with wider and longer
  lists. Not tried on those devices yet: reports welcome.
- **Adding a port** is a recipe in a pull request, checked automatically: see CONTRIBUTING.md.
